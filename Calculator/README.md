# CLI CALCULATOR

A beginner friendly command-line calculator built in python to perform basic arithmetic operations
with input validation and error handling.

---

##Features

- ➕Addition, ➖Subtraction, ✖️Multiplication, ➗Division
- 🔁Runs in a continuous loop until the user exits
- 🛡️Handles invalid inputs
- 🚫Protects against division by zero
- 📁Fully modular with reusable functions

---

##Run in your Terminal

> Make sure Python is installed on your Machine first.
